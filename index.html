設定與使用說明

美股即時報價：需要免費 Finnhub API Key。Key 只會保存在你的手機，不會上傳到其他地方。

台股輸入純數字代號，例如 2330、0050、00631L。請先部署附檔中的 Cloudflare Worker，並把 Worker 網址貼到上方。

美股輸入代號，例如 AAPL、QQQM、VT。免費資料可能有交易所延遲；畫面會顯示最後更新時間。

要像 App 一樣使用：用 Safari 開啟部署網址 → 分享 →「加入主畫面」。

本工具僅做資產彙總，不構成投資建議。即時性取決於資料供應商。
