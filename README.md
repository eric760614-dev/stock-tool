# AlphaPilot V6.1

將以下 4 個檔案上傳並覆蓋 GitHub `stock-tool` 根目錄：

- `worker.js`
- `wrangler.jsonc`
- `package.json`
- `README.md`

Commit 後 Cloudflare Git 會自動部署。

## V6.1 更新

- 持股改為精簡清單：平時只顯示股票代號與總值
- 點擊下拉箭頭才展開股數、價格、漲跌、Beta、更新時間與操作按鈕
- 配置助手自動列出目前已登入的所有股票
- 每檔直接輸入目標占總資產比例，例如 30 代表 30%，不持有填 0
- 目標比例必須合計 100%，才會進行建議買入計算
- 新增「匯出完整備份」，可存到 iPhone 檔案 App
- 新增「從檔案還原」，匯入前會顯示備份日期與持股數量並要求確認
- 備份包含持股、現金、質押、API 設定、目標比例及資產歷史
