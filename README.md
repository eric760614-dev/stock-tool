## V6.4 更新

- 配置助手獨立成新的「聰明再平衡」分頁
- 質押壓力測試與市場情境模擬合併到「風險模擬」分頁
- 質押試算也一併放入風險模擬頁
- 移除原本的「現金／質押」選單
- 現金部位移到「持股」頁，與新增持股放在同一頁
- 新增 AU9901 支援
- AU9901 是櫃買黃金現貨，不是一般上市股票，現階段需輸入手動價格
- AU9901 可正常加入資產配置、再平衡及 Beta 模型計算

## AU9901 輸入方式

1. 股票代號輸入 `AU9901`
2. 股數輸入持有單位
3. 手動價格輸入目前每單位價格
4. 按「加入持股」

由於 Yahoo Finance 與 Finnhub 沒有 AU9901 的標準即時報價，更新按鈕會保留手動價格，不會把價格清除。
