# Budget Tool V3.2

- 一般主項目圖示改為 50 種獨立貓咪圖示。
- 50 張圖示依原始 01–50 邊框逐格裁切，移除格線、編號、鄰格與畫面雜訊。
- 每張統一為 128×128、白底、置中與一致留白。
- 專屬品牌／標題／導覽圖示維持獨立，不混入一般主項目池。
- 一般主項目分配由 32 種擴充為 50 種。
- 版號 v3.2.0。

## V3.2.1
- 重新依原始 50 貓每一格的實際邊框精準裁切
- 每張再以貓咪本體輪廓做第二次內容裁切
- 排除格線、編號、鄰格殘影與邊緣雜訊
- 50 張全部統一為 128×128、白底、等比例縮放、置中
- 顯示效果統一為與原本 01 / 02 相同的乾淨格式
- PWA 快取版本同步升級到 V3.2.1

## V3.3.0
- 原本 category-cat-01~50 完整保留。
- 新生成的第二組 50 隻貓，使用與 V3.2.1 相同的精準裁切、本體二次裁切與置中邏輯。
- category 系列以外的舊專屬貓圖、品牌、導覽、對話框、備份及 App/PWA 圖示全部替換成新 50 貓。
- 新 50 貓另存 dedicated-cat-01~50。


## V3.4.0
- 新增每筆支出的付款方式：現金、轉帳、信用卡。
- 「本月實際花費」= 現金 + 轉帳 + 舊資料 + 信用卡繳款。
- 「本月消費」= 當月所有消費紀錄（含信用卡刷卡）。
- 新增獨立信用卡繳款紀錄，避免刷卡消費與繳卡費重複計算。
- V3.3.1 修正版專屬貓圖檔已完整覆蓋整合。
- 舊版資料會標記為「舊資料」，維持原本統計行為，可再逐筆編輯付款方式。
