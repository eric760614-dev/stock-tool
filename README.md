# AlphaPilot V6.2

將以下 4 個檔案上傳並覆蓋 GitHub `stock-tool` 根目錄：

- `worker.js`
- `wrangler.jsonc`
- `package.json`
- `README.md`

Commit 後 Cloudflare Git 會自動部署。

## V6.2 完整再平衡

- 新增資金可以輸入 0
- 以「目前持股市值＋新增資金」計算再平衡後的總資產
- 每檔顯示目前比例、目標比例、應買入或應賣出金額
- 目標比例填 0% 時，直接顯示「全部賣出」
- 有新增資金時，也會一起納入舊持股狀態計算
- 顯示預計賣出總額、預計買入總額及淨投入
- 比例合計必須為 100%

## 計算邏輯

每檔目標市值：

`（目前總資產 + 新增資金）× 目標比例`

調整金額：

`目標市值 - 目前市值`

- 正數：買入
- 負數：賣出
- 接近 0：無需調整
