# AlphaPilot V12.1.0

## 本次新增

- 聰明再平衡支援「同性質資產群組」。可將 00662 + QQQM 等視為同一配置目標，例如兩者合計 20%。
- 群組內不強迫個別比例；系統會依目前持有部位、台股/美股市場與可用資金來源推薦增減標的。
- 優先同市場資金互轉：美股賣出資金優先補美股標的，台幣/台股資金優先補台股標的，以減少不必要換匯。
- 未加入群組的股票仍可設定個別目標比例；「群組目標 + 個別目標」合計須為 100%。
- 新增「手動 Beta」欄位。新上市或歷史資料不足時可自行輸入 Beta；手動值不會被「更新全部」覆蓋。
- 持股修改功能可切換手動 Beta / 恢復自動 Beta。
- Investment Score 的配置分數同步支援群組目標。

## 部署

```bash
npm install
npx wrangler deploy
```
