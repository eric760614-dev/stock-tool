# 投資資產儀表板 v3.3

## 新功能
- 將原本橫向頁籤改成右上角三條線選單。
- 點擊三條線後，從右側滑出功能選單。
- 每個功能都有圖示：
  - 📈 持股
  - 🥧 資產配置
  - 💰 現金／質押
  - 🕘 資產歷史
  - ⚙️ 設定
- 點選功能後會自動切換內容頁面並關閉選單。
- 支援點擊背景或按 Esc 關閉選單。
- 更新 Safari Service Worker 版本。
