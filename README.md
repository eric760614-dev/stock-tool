- 持股：藍色玻璃
- 現金：青綠玻璃
- 資產配置：青色玻璃
- Beta／風險：紫色玻璃
- 聰明再平衡：綠色玻璃
- 質押：橘色玻璃
- 固定支出：金色玻璃
